# 集群内部接口鉴权（/inner/**）

## 你要做的事

在 Nacos 公共配置 `nilo-common.yaml`（各服务已 `import` 这份）中增加：

```yaml
nilo:
  internal:
    enabled: true
    # 换成足够长的随机串，不要提交到 git
    token: "请替换成你自己的随机密钥"
```

配好后**重启各服务**即可，无需改任何 Controller / Feign 接口方法。

## 原理（不用改业务代码）

| 方向 | 做什么 |
|------|--------|
| 出站 | Feign 拦截器自动给所有 Feign 请求加上请求头 `X-Internal-Token` |
| 入站 | Web 拦截器拦截 `/inner/**`，校验该请求头是否与配置一致 |

错误时返回业务码 `1007`（没有权限）。

## Nginx 建议（双保险）

公网反代里拒绝内部路径：

```nginx
location ^~ /inner/ {
    return 403;
}
```

## 关闭（仅本地调试必要时）

```yaml
nilo:
  internal:
    enabled: false
```

未配置 `token` 且保持 `enabled: true` 时，`/inner/**` 会被拒绝（宁可拦死，也不要裸奔）。
